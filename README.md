## 🧠 Featured Project

**[HBALS-TSP](https://github.com/ErfanKhadiv/HBALS-TSP)** — A hybrid Bees Algorithm with adaptive local search (2-opt/3-opt) for the Traveling Salesman Problem. Benchmarked against BA, ACO, GA, and PSO on TSPLIB instances, outperforming all four on solution quality across every tested dataset. Includes a full reproducible benchmark suite: all 5 algorithms, all datasets, all results. A sole-authored manuscript describing the work has been submitted to *Evolutionary Intelligence* (Springer).
