## 🧠 Featured Project

**[HBALS-TSP](https://github.com/ErfanKhadiv/HBALS-TSP)** — A hybrid Bees Algorithm with adaptive local search (2-opt/3-opt) for the Traveling Salesman Problem.

- Benchmarked against **BA, ACO, GA, and PSO** on six TSPLIB instances (up to 195 cities)
- Lowest best-tour length on all six instances; differences are statistically significant against BA and GA, but not against ACO and PSO
- Fully reproducible benchmark suite: all 5 algorithms, all datasets, all results
- Limitations, including that no ablation study has been done yet, are documented in the repo
- Sole-authored manuscript submitted to *Evolutionary Intelligence* (Springer)
